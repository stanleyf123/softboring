# Nickname links, week-chip empties, intention distance

No new environment variables. Stripe and email are not required. SQLite is unchanged.

## Nickname strip links

Homepage nickname chips open Soft Wall with `?nick=`. The name is checked the same way a saved nickname is: two to sixteen characters, no `@`, no control characters. Free search and Soft+ search start with that name, using notes already on the page. Nothing extra is loaded, and email addresses stay off the strip.

## Quiet week-chip empties

When Soft+ rests the corkboard on this ISO week or on earlier weeks, and no note matches, the board says so in its own words and offers “show all weeks.” Search, feeling range, and hide-demo still use the wider “nothing matches” empty. Notes are not removed.

## Earlier intentions, a little closer

Soft+ intention history still lists past weeks only. Each sentence can say “last week” or how many weeks ago, next to the ISO week key, and can be copied on this device. The sentence is not emailed and does not go to Soft Wall.
