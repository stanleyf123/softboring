# Soft memory, quiet writing, Soft Wall flags

No new environment variables. Stripe and email are not required.

## Soft memory resurfacing

Signed-in Home and Account may show **a soft note from then** — one review excerpt from **4+ weeks ago**, about two of every three UTC days. Soft+ sees the excerpt and a History link. Free sees the full note only if that week is still in the free history window; otherwise a gentle teaser.

## Quiet writing on `/review`

A **Quiet writing** toggle hides header, footer, bottom nav, onboarding, and the intention/note chrome while you write. Session-scoped (`sessionStorage`). A fixed **Exit quiet mode** control stays available.

## Soft Wall unshare + “this feels off”

Soft+ owners get a clearer unshare block on note detail (still deletes the wall pin; History stays private). Soft+ viewers can optionally tap **This feels off** — one quiet flag per person per note (`wall_note_flags`). Admin `/admin/wall` lists flag counts (flagged rows first) and can still hide notes.
