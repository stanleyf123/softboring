# Soft Wall guest search, desk size, pin window

No new environment variables. Stripe and email are not required. SQLite is unchanged.

## Guest search on Soft Wall

Guests and free members already see a locked corkboard: color, place, and nickname. A cream search box filters those notes in the browser by nickname. If a note already carries open words (a Soft+ note), the same filter can match them too. Blurred review text is not loaded for the search. Feeling range, demo mute, and sort stay on Soft+. The query lasts for this visit only.

## Account soft size note

Signed-in members see a quiet count on Account: reviews saved with the desk, and Soft Wall notes stored for them, including notes taken down. The numbers are a snapshot, not a byte measure. Nothing is emailed.

## Pin window where you share

Free can pin the weeks History keeps open (the latest four). Soft+ can pin older weeks as well. Raising one of your notes above the others is already limited to a single note, and only Soft+ can do it. The share card says so. No checkout is started.
