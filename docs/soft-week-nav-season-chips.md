# Open weeks, seasonal phrasing, wall week chips

No new environment variables. Stripe and email are not required. SQLite is unchanged.

## Open-week navigation

An open review can step to the earlier or later open week. The list is newest-first. Locked weeks are skipped, so a free desk never links into a tucked week. If this is the only saved week, it says so. If older weeks are tucked, it mentions that Soft+ opens them. Neighbor titles are the saved sentence, trimmed. Nothing is emailed.

## Seasonal question phrasing

Guests and members can hear the same six questions in spring, summer, autumn, or winter wording for this visit. The month on this device picks the season. Answers still save in the usual fields. This is not a Soft+ pack. If a Soft+ pack is tried for the review, that pack speaks instead and the seasonal chips step aside.

## Soft+ wall week chips

Soft+ can rest the corkboard on all weeks, this ISO week, or earlier weeks. The week follows the account timezone (Taipei when none is saved). A future week, or a note without a date, stays visible only on “all weeks.” Free teasers do not get the chips. Notes are not removed from the wall.
