# Gift-code empty state, review draft restore, past-letter inbox

No new environment variables. Stripe and email are not required.

## A mint empty state for Soft+ gift codes

`/admin/gifts` still mints one-time codes in Traditional Chinese. When the table is empty, a mint card explains the three quiet steps: choose days or permanent Soft+, mint without charging Stripe, and hand the code to a member to redeem on Account. Nothing is emailed. After the first code exists, the audit table returns.

## A clearer restore for a local review draft

If this device already has an unsent weekly review, the form still opens with those words and keeps autosaving. A cream banner offers two actions: bring back the version from when the page opened, or let the draft go. Letting go clears only this device. The banner is hidden when printing, and it does not animate.

## A Soft+ inbox of letters to past weeks

Soft+ sees those short letters on the account page, newest first, still inside the app. Each row links back to that week. Free members see an upgrade tease; the latest four reviews stay open. The history shelf keeps its short list and links Soft+ to the inbox. Letters are not emailed and are not added to the review download.
